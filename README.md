# lf-slides

Hospedagem das imagens dos carrosseis do Instagram da marca "Liberdade Financeira na Pratica" (@liberdade.financeira.napratica).

Os arquivos ficam em carrosseis/<data>_<turno>/slideN.jpg e sao servidos pelo raw.githubusercontent.com, que e o endereco publico usado pela API do Instagram para baixar as imagens na hora de publicar o carrossel.

Por isso este repositorio precisa continuar publico.
